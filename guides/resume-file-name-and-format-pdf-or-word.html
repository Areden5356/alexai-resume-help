Resume file name and format: PDF, Word or text

Updated 21 October 2026

A good resume can still make a poor first impression as resume final v7 (2).docx, or be rejected because the employer asked for one format and received another. This guide covers three small decisions: which format to send, what to name the file, and what to check before you upload. Where an official source says something, I cite it. The file name advice is my own judgment, and I say so.

Follow the employer's instruction first

CareerOneStop, a US Department of Labor sponsored site, advises sending only the documents requested, in the format the posting specifies. Purdue's writing lab makes a related point about job ads: check how the employer wants to receive your materials, for example by email or through an online application, and whether they want a resume, an application form or both. So read the posting and the application page for phrases such as "upload a PDF" or "Word documents only" before you save anything.

When no format is named

CareerOneStop says to use Word, PDF or plain text files when the posting does not specify. Here is what each does, in plain terms:

  • PDF. The page looks the same on any screen, because the layout is stored in the file. It is harder for a reader to edit.
  • Word. Easy for the employer to edit, but the layout can shift when it is opened with a different version of the software or without your fonts.
  • Plain text. No layout at all, so any system can read it, and you lose bold, columns and spacing.

I could not find an authoritative source saying that applicant tracking software reads PDF better than Word, or the reverse, so I do not claim either. If you are unsure, the copy-paste test below tells you more about your own file than a general rule can.

Never send a picture of a resume

CareerOneStop warns against scanning a resume and sending it as an image, because software will not recognize the text. A phone photo has the same problem, and so does a PDF made from a scan. A quick test: open the file and try to select a word with the cursor. If you cannot, the file is a picture.

Length

CareerOneStop's advice is to keep a resume to 1 to 2 pages. For most students and new graduates, my judgment is that one page is enough, and the bullets guide says what to cut first.

Naming the file (my judgment)

I found no authoritative guidance on file names, so treat this as practical advice. A recruiter may download many files into one folder. A name that identifies you and says what the file is makes yours easy to find.

Example, invented for illustration 
Good:   Jordan-Example-Resume.pdf
Weak:   Resume.pdf
Weak:   resume final FINAL v7 (2).docx
Weak:   Jordan Example Resume for Trailhead Supply.pdf
  • Use your name and the word Resume. Plain "Resume.pdf" is the same name every applicant uses.
  • Skip version words and dates. "Final" and "v7" tell the reader you keep many versions.
  • Leave the employer's name out of the file name. If you reuse a file and forget to rename it, the wrong company's name goes to the other company. Put the employer in a folder name on your own computer instead.
  • Use hyphens or underscores instead of spaces. Spaces usually work. A hyphen is the safer habit, and I have not verified a case where it matters.
  • Keep private details out of the name. No student number, no birth date.

Check the file before you upload

  1. Open the saved file, not the original. Open the PDF in a browser. Look for moved lines, missing symbols and a page count that changed.
  2. Run the copy-paste test. Select all, copy, and paste into a plain text editor. If the order is scrambled or words are missing, the layout is too complicated. The formatting guide explains how to fix that.
  3. Check the file's own details. Some programs store a title and an author name inside the file. Look in the file properties for anything left from an old document.
  4. Use the preview screen. CareerOneStop advises checking the preview of an online application for accuracy before you submit it.

Keep one master and a tidy folder

Keep one editable master in Word or Google Docs. For each application, make a folder named for the employer and save the PDF inside it under your clean file name. The folder tells you which version went where, and the file name stays clean for the reader. Note the date you applied and the posting wording in the same folder, since you may need it before an interview.
